# 🧠 Memoria del Proyecto: `el_velo_gravitacional`

## 📌 Descripción del Proyecto
Proyecto editorial y audiovisual de ciencia ficción / narrativa: **"El Velo Gravitacional"**. Contiene la Biblia del Universo (`BIBLIA_DEL_UNIVERSO.tex` / `.pdf`), el compilado profesional del libro (`COMPILADO_libro_PROFESIONAL.tex` / `.pdf`), assets visuales (`assets/`) y guiones para aplicación web (`guiones_webapp/`).
